# Epic 2 Retrospective — Folder Mode

**Date:** 2026-04-25
**Epic:** 2 — Folder Mode
**Stories:** 3 (all done)

## Summary

Folder Mode: tree browser, breadcrumb/file playback, and cue/DSD normalization. First mode built alongside the existing Album mode.

## What Went Well

- **MPD lsinfo integration**: Protocol parsing for directory browsing works reliably. Format badge computation (DSD rates, PCM bit depth/sample rate) correctly parses MPD's Format and Audio fields.
- **Breadcrumb navigation**: Clickable path segments with GestureClick provide intuitive navigation. Root "~" clickable to return home.
- **Mode switching**: Ctrl+1/Ctrl+2 keyboard shortcuts with View menu work cleanly. Visibility toggling between album and folder content boxes.
- **File playback from folder**: `PlayFile` command (clear + add + play) wired through the state machine correctly.
- **Cue/DSD detection**: Case-insensitive extension matching, audio file skip lists, and summary entries for normalized directories.
- **Cross-cutting bug fixes**: lsinfo path construction doubled file paths (fixed), several review findings addressed across all stories.

## Challenges

- **Tree vs flat list**: The folder browser uses a drill-down ListBox rather than an expandable tree. This was flagged in review but accepted as a v1 simplification. Proper tree with disclosure arrows and indentation would need TreeListModel/ColumnView.
- **Row activation dispatch bug**: Critical bug where row activation inspected the wrong widget (hbox instead of icon label), making all navigation and file playback completely non-functional. Caught in code review.
- **DSD rate badge formula**: Wrong double-multiplication (`mult * 64`) produced "DSD4096" instead of "DSD64". Caught in code review.
- **DirectoryListing event path**: Event carried entries but not the listed path, causing stale breadcrumb after navigation. Fixed by adding path to the event variant.
- **CSS classes for breadcrumb/queue**: Multiple CSS classes defined but no corresponding rules in the provider. Several review findings about invisible styling.

## Key Insights

- **Code review caught critical bugs**: Row activation dispatch, DSD badge formula, DirectoryListing path — all would have shipped broken without review. The review process is effective.
- **Widget tree traversal is fragile**: `row.child()` vs `icon.set_widget_name()` mismatch shows that widget name/class should be set on the container, not a child.
- **Case-insensitive matching matters**: Extension matching and MPD response parsing should handle both cases for real-world compatibility.
- **Commit to tree or drill-down**: The flat ListBox approach works but users expecting a real tree will be confused. A future story should consider TreeListModel/ColumnView.
